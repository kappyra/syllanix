# Syllanix — «Python: от нуля до профессиональной разработки»

**Читать онлайн: <https://kappyra.github.io/syllanix/>**

Открытый учебник по Python на русском языке: 56 глав, 11 частей, более 500
упражнений с решениями и 109 оригинальных иллюстраций. От первого выражения
до внутреннего устройства языка, архитектуры, асинхронности и прикладных
проектов.

## Как читать

- **Сайт (рекомендуется):** <https://kappyra.github.io/syllanix/> — поиск,
  оглавление, карта обучения, мобильная вёрстка.
- **Карта обучения:** <https://kappyra.github.io/syllanix/map.html> —
  интерактивная карта частей, глав и понятий.
- **EPUB / один HTML:** в этом репозитории нет бинарных сборок; их можно собрать
  из Markdown-исходников (см. ниже) или читать главы напрямую в `book/`.

## Структура

```
index.html, *.html      — собранный статический сайт (GitHub Pages)
book/
  book.yaml             — манифест книги: части, главы, порядок
  chapters/*.md         — 56 глав (одна глава = один файл)
  solutions/*.md        — решения упражнений (отдельно от условий)
  illustrations/*.svg   — 109 оригинальных SVG
  provenance/*.yaml     — происхождение переработанных фрагментов
  history.md, preface.md, learning-map.md, glossary-guide.md, …
sources/
  registry.yaml         — реестр источников (только совместимые лицензии)
  licenses/             — копии текстов лицензий
  research/fragments.yaml — инвентарь переиспользуемых фрагментов
  reports/              — аудит лицензий
```

## Как собрать локально

Понадобятся Python 3.11+ и пакетный менеджер `uv`.

```bash
# сайт собирается собственным генератором Syllanix; исходники и сборщик
# поставляются в полном репозитории проекта (здесь — только публикуемая книга
# и готовый сайт).
```

Публичный репозиторий содержит **готовый сайт** и **Markdown-исходники книги**;
служебный harness и граф знаний в публикацию не входят по требованию владельца.

## Безопасность

См. `SECURITY.md`. Сайт статический: нет серверной логики, нет пользовательского
ввода, нет внешних скриптов; действует CSP. Сообщения об уязвимостях — через
GitHub Security Advisories.

## Обновление

Публикация обновляется из основного репозитория проекта: Markdown-главы
собираются в статический сайт и выкладываются в этот репозиторий.
