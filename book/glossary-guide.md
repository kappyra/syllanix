# Словарь программиста

Профессиональный разработчик говорит на общем языке. Эта страница —
навигатор по терминам книги: как ими пользоваться, какие различать и где
смотреть полный список.

Полный глоссарий (408 терминов en ↔ ru с определениями) — страница
«Глоссарий» на сайте и файл `glossary/glossary.yaml`. Здесь — то, что важно
понять до начала чтения.

## 1. Зачем нужен словарь

Термин — это инструмент мышления. Пока вы говорите «переменная» и имеете в
виду три разных вещи, ошибки неизбежны. Книга вводит каждое понятие один раз
и дальше использует его единообразно; глоссарий фиксирует это соглашение.

Правило книги: **один термин — одно значение**. Если в тексте встречается
«итератор», это всегда объект с `__next__`, а не «то, по чему можно
перебрать».

## 3. Слои терминологии

1. **Язык.** Значения, объекты, имена, типы, выражения, инструкции —
   фундамент, без которого нельзя читать документацию.
2. **Программирование.** Алгоритм, сложность, рекурсия, состояние,
   побочный эффект, чистая функция — общие понятия, не привязанные к Python.
3. **Инженерия.** Тесты, CI, ревью, зависимости, рефакторинг, инцидент —
   то, что отличает «пишет код» от «делает продукт».
4. **Экосистема.** Пакет, виртуальное окружение, lock-файл, колесо (`wheel`),
   индекс пакетов — словарь инструментов.

В книге эти слои вводятся последовательно: не стоит объяснять «запах кода»
до того, как читатель написал хотя бы одну функцию (глава 53 идёт после
практики).

## 4. Как пользоваться глоссарием

- **При чтении:** если термин встретился впервые — он определён в главе; если
  нужен быстрый ответ — откройте «Глоссарий» на сайте и найдите en/ru.
- **При письме:** используйте предпочтительный русский вариант из глоссария;
  запрещённые варианты перечислены там же (например, для `iterator` нельзя
  писать «итерируемый объект»).
- **При переводе/локализации:** сопоставление `concept id → термин` лежит в
  `localization/ru/term-map.yaml`; идентификаторы понятий не зависят от языка.

## 5. Термины, которые часто переводят неверно

| English | Правильно | Неправильно |
|---|---|---|
| iterator | итератор | «итерируемый объект» |
| iterable | итерируемый объект | «итератор» |
| argument | аргумент | «параметр» (когда речь об аргументе) |
| parameter | параметр | «аргумент» |
| statement | инструкция | «выражение» |
| expression | выражение | «инструкция» |
| shallow copy | поверхностное копирование | «глубокая копия» |
| deep copy | глубокое копирование | «поверхностное копирование» |
| mutability | изменяемость | «изменчивость» |
| closure | замыкание | «кложур» |
| code smell | запах кода | «код-смелл» |
| refactoring | рефакторинг | «переписывание» |
| technical debt | технический долг | «техдолг» (в книге — полностью) |
