# Решения к главе 23

Короткая запись полезна, когда её смысл виден сразу. В решениях ниже обратите
внимание не только на результат, но и на то, что исходные коллекции остаются
неизменными.

## 1. Прогнозирование вывода {#sol-ch23-01}

```python exec
numbers = [1, 2, 3, 4]
result = [n * n for n in numbers if n % 2 == 0]
print(result)
print(numbers)
```

```output
[4, 16]
[1, 2, 3, 4]
```

Условие `n % 2 == 0` пропускает только чётные числа, а `n * n` превращает их в
квадраты. Исходный список не меняется: включение строит новый.

## 2. Первое включение {#sol-ch23-02}

```python exec
data = [5, 12, 7, 20]
big = [n for n in data if n > 10]
squares = [n * n for n in big]
print(big)
print(squares)
```

```output
[12, 20]
[144, 400]
```

Два включения можно объединить в одно, но отдельные строки понятнее, когда
промежуточный результат имеет смысл.

## 3. Словарное включение {#sol-ch23-03}

```python exec
prices = {"яблоко": 90, "банан": 120}
raised = {name: round(price * 1.1) for name, price in prices.items()}
print(prices)
print(raised)
```

```output
{'яблоко': 90, 'банан': 120}
{'яблоко': 99, 'банан': 132}
```

`prices.items()` даёт пары «ключ, значение», а включение строит новый словарь.
Исходный словарь не изменился — это видно по первому выводу.

## 4. Множественное включение {#sol-ch23-04}

```python exec
words = ["кот", "пёс", "кот", "рысь"]
firsts = {word[0] for word in words}
print(sorted(firsts))
print(len(firsts), len(words))
```

```output
['к', 'п', 'р']
3 4
```

Слов четыре, но буквы повторяются: `к` встречается у двух слов. Множество
хранит только уникальные значения, поэтому элементов три. `sorted` нужен для
устойчивого вывода: порядок элементов множества не гарантируется.

## 5. Лямбда или def {#sol-ch23-05}

- удвоить число в аргументе `key` — лямбда: короткое выражение, нужное один
  раз;
- проверить пароль на длину и цифру — обычная функция: два условия и смысл,
  который стоит назвать;
- взять последнюю букву слова — годится и лямбда, и маленькая функция.

Для третьего случая обычная функция читается лучше:

```python exec
def last_char(word):
    return word[-1]


print(sorted(["кот", "мышь", "слон"], key=last_char))
print(sorted(["кот", "мышь", "слон"], key=lambda word: word[-1]))
```

```output
['слон', 'кот', 'мышь']
['слон', 'кот', 'мышь']
```

Результат одинаков, но `last_char` можно переиспользовать и прочитать её имя в
ключе сортировки.

## 6. map и filter {#sol-ch23-06}

```python exec
numbers = [3, -4, 0, 5]
absolute = list(map(abs, numbers))
non_negative = list(filter(lambda n: n >= 0, numbers))
print(absolute)
print(non_negative)
```

```output
[3, 4, 0, 5]
[3, 0, 5]
```

`list` нужен потому, что `map` и `filter` возвращают итераторы, а не списки.
Без `list` в выводе оказалось бы `map object at ...` — служебное описание
объекта, а не значения. Кстати, для модуля чисел `map(abs, numbers)` красивее
лямбды: готовая функция уже делает нужное.

## 7. Включение вместо map {#sol-ch23-07}

```python exec
numbers = [1, 2, 3]
print(list(map(lambda x: x + 1, numbers)))
print([x + 1 for x in numbers])
```

```output
[2, 3, 4]
[2, 3, 4]
```

Включение предпочтительнее: оно короче, не требует `list` и явно говорит, что
строится список. `map` остаётся удобным, когда функция уже есть и не нужно
оборачивать её в лямбду.

## 8. Сортировка по двум признакам {#sol-ch23-08}

```python exec
goods = [("яблоко", 90), ("банан", 90), ("вишня", 350)]
ordered = sorted(goods, key=lambda item: (-item[1], item[0]))
print(ordered)
```

```output
[('вишня', 350), ('банан', 90), ('яблоко', 90)]
```

Минус перед ценой переворачивает порядок по цене: большие значения идут
раньше. Второй элемент ключа — название — разрешает ничьи по возрастанию.
Без минуса пришлось бы сортировать дважды: сначала по названию, затем
устойчивой сортировкой по цене.

## 9. Мини-проект: отчёт по оценкам {#sol-ch23-09}

```python exec
grades = {"Анна": [4, 5, 5], "Борис": [3, 4], "Вера": [5, 5, 4]}
averages = {
    name: round(sum(marks) / len(marks), 1)
    for name, marks in grades.items()
}
print(averages)
best = [name for name in averages if averages[name] > 4]
print(best)
ordered = sorted(averages.items(), key=lambda item: item[1], reverse=True)
print(ordered)
```

```output
{'Анна': 4.7, 'Борис': 3.5, 'Вера': 4.7}
['Анна', 'Вера']
[('Анна', 4.7), ('Вера', 4.7), ('Борис', 3.5)]
```

Три инструмента решили три разные задачи: словарное включение посчитало
средние, включение с условием выбрало отличников, `sorted` с ключом упорядочил
пары. Порядок при равных средних сохранился исходный: Анна стоит в словаре
раньше Веры, поэтому и в результате она первая. Это устойчивость сортировки.

## 10. Чистая функция {#sol-ch23-10}

```python exec
def apply_discount(prices, percent):
    return {
        name: round(price * (100 - percent) / 100)
        for name, price in prices.items()
    }


prices = {"яблоко": 90, "банан": 120}
discounted = apply_discount(prices, 10)
print(prices)
print(discounted)
```

```output
{'яблоко': 90, 'банан': 120}
{'яблоко': 81, 'банан': 108}
```

Функция чистая: она строит новый словарь и не меняет аргумент, поэтому
одинаковый вызов всегда даёт одинаковый результат.

Нечистый вариант меняет словарь на месте:

```python exec
def apply_discount_in_place(prices, percent):
    for name in prices:
        prices[name] = round(prices[name] * (100 - percent) / 100)
    return prices


prices = {"яблоко": 90}
print(apply_discount_in_place(prices, 10))
print(prices)
```

```output
{'яблоко': 81}
{'яблоко': 81}
```

Разница видна по второму выводу: после нечистой функции исходный словарь
изменился. Такой вариант иногда нужен ради экономии памяти, но вызывающий код
обязан знать о побочном эффекте.

## Ответы на вопросы для самопроверки

1. Включение состоит из выражения-результата, части `for` и необязательного
   условия `if`; читается слева направо.
2. Словарное включение содержит двоеточие между ключом и значением,
   множественное — нет; фигурные скобки без двоеточия означают множество.
3. Лямбда уместна для короткого одноразового выражения, особенно в `key`;
   сложную логику лучше назвать обычной функцией.
4. `map` и `filter` возвращают итераторы; `list` материализует результат,
   чтобы его можно было вывести или перебрать повторно.
5. Ключ возвращает кортеж: минус у первого признака даёт убывание, второй
   признак задаёт порядок при равенстве.
6. Чистая функция зависит только от аргументов и не меняет внешнее
   состояние; функция с побочным эффектом меняет аргументы, файлы или
   глобальные данные.
7. `print` возвращает `None`, поэтому список состоит из `None`; вывод — это
   побочный эффект, а не значение.
