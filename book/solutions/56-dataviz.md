# Решения к главе 56

Решения отделены от условий. Примеры с matplotlib даны как иллюстративные
блоки: библиотека сторонняя и может быть не установлена, поэтому проверяемые
`exec`-блоки готовят данные и проверяют подготовку, а рисование показано
отдельно.

## 1. Вопрос и форма {#sol-ch56-01}

| Вопрос | Форма | Почему |
|---|---|---|
| как менялась посещаемость по неделям | линия | порядок задан, важна форма изменения |
| сколько студентов в каждой группе | столбцы | длины сравниваются точно |
| как распределены оценки | гистограмма | частоты по интервалам |
| связаны ли часы подготовки и балл | точки | пары значений, видна тенденция |
| какую долю занимает статья бюджета | столбцы или стек | доли читаются точнее секторов |

Круговая диаграмма уместна только для нескольких крупных долей, которые
сильно различаются. Если доли близки, сектора сливаются, и читатель не может
сравнить их. Столбцы в такой ситуации честнее: длина сравнивается точнее
угла, а подписанные значения убирают догадки. Для распределения важна форма:
симметричное оно или скошено, есть ли второй пик и выбросы.

## 2. Анатомия графика {#sol-ch56-02}

В описании графика не хватает пяти элементов.

1. **Заголовка** — непонятно, что и за какой период показано.
2. **Единиц на оси Y** — числа от 0 до 3000 могут означать рубли, штуки или
   проценты; сравнение невозможно.
3. **Подписи оси X** — шесть категорий без названий не дают понять, что
   сравнивается.
4. **Легенды** — две линии без подписей: неизвестно, какая из них что.
5. **Источника и периода** — данные нельзя проверить.

Дополнительно стоит проверить диапазон оси: начинается ли она с нуля и
одинаковы ли условия для двух линий. Если линии в разных единицах, их нельзя
сравнивать на одной оси — нужны две оси с явной оговоркой или два отдельных
графика.

## 3. Подготовка данных {#sol-ch56-03}

```python exec
raw = ["2026-03,1200", "2026-04,1500", "2026-05,900"]

def split_rows(lines):
    months = []
    values = []
    for line in lines:
        month, value = line.split(",")
        months.append(month)
        values.append(int(value))
    return months, values

months, values = split_rows(raw)
print("месяцы:", months)
print("значения:", values)
print("длины совпадают:", len(months) == len(values))
print("все целые:", all(isinstance(value, int) for value in values))
```

```output
месяцы: ['2026-03', '2026-04', '2026-05']
значения: [1200, 1500, 900]
длины совпадают: True
все целые: True
```

Функция возвращает две последовательности одинаковой длины — ровно то, что
ожидает matplotlib. Преобразование в `int` важно: если оставить строки,
график либо упадёт, либо построит категориальную ось вместо числовой.
Подготовку легко проверить тестом: длина, тип, порядок.

## 4. Обрезанная шкала {#sol-ch56-04}

```python exec
values = [240, 250, 260]

def heights(values, baseline):
    return [value - baseline for value in values]

for baseline in (0, 230):
    bars = heights(values, baseline)
    print(f"база {baseline}: высоты {bars}, отношение крайних {bars[0] / bars[2]:.2f}")
print("отношение значений:", round(values[0] / values[2], 3))
```

```output
база 0: высоты [240, 250, 260], отношение крайних 0.92
база 230: высоты [10, 20, 30], отношение крайних 0.33
отношение значений: 0.923
```

При нулевой базе крайние столбцы отличаются примерно на 8 % — это честная
картина. При базе 230 высоты становятся 10, 20 и 30: третий столбец выглядит
втрое выше первого, хотя значения различаются всего на 20 единиц из 240.
Для столбцов длина кодирует величину, поэтому обрезанная ось искажает смысл;
честный вариант — нулевая линия, а разницу лучше показать подписями значений.

## 5. Гистограмма {#sol-ch56-05}

```python exec
values = [12, 15, 18, 18, 21, 24, 24, 27, 30, 35, 41, 44, 47, 52]

def histogram(items, width):
    bins = {}
    for value in items:
        start = value // width * width
        bins[start] = bins.get(start, 0) + 1
    return sorted(bins.items())

print("ширина 10:", histogram(values, 10))
print("ширина 5:", histogram(values, 5))
```

```output
ширина 10: [(10, 4), (20, 4), (30, 2), (40, 3), (50, 1)]
ширина 5: [(10, 1), (15, 3), (20, 3), (25, 1), (30, 1), (35, 1), (40, 2), (45, 1), (50, 1)]
```

При ширине 10 видны пять групп и общая форма: основная масса значений
сосредоточена между 10 и 30. При ширине 5 появляются детали — например,
скачок в интервале 15–20 — но одновременно становится заметнее шум от
маленьких частот. Число интервалов выбирают по объёму данных: чем меньше
значений, тем крупнее интервал, иначе столбики по одному наблюдению ничего не
показывают.

## 6. Две серии {#sol-ch56-06}

```python exec
months = ["янв", "фев", "мар", "апр"]
fact = [1200, 1500, 900, 2100]
plan = [1100, 1300, 1400, 1900]

deviation = [actual - target for actual, target in zip(fact, plan)]
completion = [round(actual / target * 100) for actual, target in zip(fact, plan)]
print("отклонение:", deviation)
print("выполнение, %:", completion)
print("план перевыполнен месяцев:", sum(1 for value in completion if value >= 100))
```

```output
отклонение: [100, 200, -500, 200]
выполнение, %: [109, 115, 64, 111]
план перевыполнен месяцев: 3
```

Отклонение в единицах измерения удобно для графика: оно сохраняет масштаб
данных и показывает, где именно провал. Проценты выполнения удобны в отчёте:
они позволяют сравнивать месяцы с разным планом. Для графика достаточно
первого списка — он в тех же единицах, что и исходные значения; второй список
лучше давать таблицей рядом.

## 7. Честность {#sol-ch56-07}

В описании три проблемы.

1. **«Выручка выросла на 300 %»** — непонятно, за какой период и от какого
   значения. Скорее всего, перепутаны «выросла на 300 %» и «выросла в 3 раза»:
   это разные величины.
2. **«Ось Y начинается с 950»** — при таком начале столбцы или площади
   искажают пропорции; если это столбцы, ось должна начинаться с нуля, иначе
   разница выглядит драматичнее реальной.
3. **«Вторая линия — количество сотрудников», «единицы не указаны»** — две
   разные величины в разных единицах на одной оси несравнимы: нужно либо две
   оси с явной оговоркой, либо два графика; единицы обязательны.

Дополнительно стоит указать период данных, источник и, если данных мало,
размер выборки. Подпись «данные за март» без года тоже двусмысленна.

## 8. Корреляция и причина {#sol-ch56-08}

Совместный рост продаж мороженого и числа утоплений не означает, что
мороженое топит людей. Два правдоподобных объяснения без причинной связи:

1. **Общая причина — погода.** В жару и мороженое покупают чаще, и люди чаще
   купаются; обе величины растут из-за третьего фактора.
2. **Общая причина — сезон.** Летом растёт и то и другое; связь исчезнет, если
   сравнивать недели внутри одного сезона.

Разобраться помогли бы данные с разделением по температуре и по месяцам:
если внутри одинаковой погоды связь пропадает, причина не в мороженом.
На графике честно писать «связь», а не «влияние», и не подписывать ось
«причина».

## 9. Экспорт {#sol-ch56-09}

Для PDF-отчёта лучше SVG: векторный формат не теряет чёткости при
масштабировании и печати, а текст в нём остаётся текстом (его можно выделить
и найти). Для презентации удобнее PNG с разрешением `dpi=300`: он
открывается везде и не требует поддержки векторных форматов.

```python python
fig.savefig("report.svg")                                # отчёт
fig.savefig("slide.png", dpi=300, bbox_inches="tight")   # презентация
```

Разница принципиальна: растровый формат хранит точки и при увеличении
размывается; векторный хранит команды рисования и масштабируется без потерь.
`bbox_inches="tight"` убирает лишние поля и не даёт обрезать подписи осей.

## 10. Мини-задача: отчёт по месяцам {#sol-ch56-10}

Сначала конвейер подготовки данных — его можно проверить без matplotlib.

```python exec
import csv
import io

raw = """month,revenue,plan
2026-01,1200,1100
2026-02,1500,1300
2026-03,900,1400
2026-04,2100,1900
"""
reader = csv.DictReader(io.StringIO(raw))
rows = sorted(reader, key=lambda row: row["month"])
months = [row["month"] for row in rows]
fact = [int(row["revenue"]) for row in rows]
plan = [int(row["plan"]) for row in rows]
deviation = [actual - target for actual, target in zip(fact, plan)]
print("месяцы:", months)
print("факт:", fact)
print("план:", plan)
print("отклонение:", deviation)
print("лучший месяц:", months[fact.index(max(fact))])
```

```output
месяцы: ['2026-01', '2026-02', '2026-03', '2026-04']
факт: [1200, 1500, 900, 2100]
план: [1100, 1300, 1400, 1900]
отклонение: [100, 200, -500, 200]
лучший месяц: 2026-04
```

Затем рисование по готовым спискам.

```python
import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(9, 4.5))
ax.plot(months, fact, marker="o", label="Факт")
ax.plot(months, plan, marker="s", linestyle="--", label="План")
ax.set_title("Выручка и план по месяцам, 2026")
ax.set_xlabel("Месяц")
ax.set_ylabel("Выручка, тыс. ₽")
ax.set_ylim(bottom=0)
ax.legend(title="Серия", loc="upper left")
ax.grid(True, axis="y", alpha=0.3)
fig.tight_layout()
fig.savefig("report.png", dpi=300, bbox_inches="tight")
fig.savefig("report.svg")
```

Проверки, которые стоит сделать до рисования: месяцы идут по порядку, длины
трёх списков совпадают, значения — числа, отклонение совпадает с разностью
«факт минус план» для каждого месяца. Если бы данные пришли в другом порядке,
сортировка по `month` восстановила бы хронологию; если бы в CSV попал пустой
месяц, конвейер упал бы с понятной ошибкой преобразования, а не нарисовал
график с дырой.

## Ответы на вопросы для самопроверки

1. Динамика — линия, сравнение — столбцы, распределение — гистограмма или
   ящик, связь — точки. Части целого показывают столбцами или стеком,
   круговую диаграмму применяют осторожно.
2. Без заголовка непонятен предмет, без единиц — масштаб, без подписи оси X —
   категории, без легенды — серии, без источника — достоверность.
3. У столбцов длина кодирует значение, поэтому нулевая линия обязательна. У
   линий положение кодирует изменение, и ненулевая нижняя граница допустима,
   если шкала видна и подписана.
4. Объектная модель не зависит от глобального состояния: фигуры и оси
   передаются явно, поэтому код предсказуем и пригоден для нескольких
   графиков.
5. Подготовка данных проверяется тестами без установки библиотеки; рисование
   можно заменить, а данные — переиспользовать в таблице или отчёте.
6. PNG — растровый, зависит от разрешения; SVG — векторный, масштабируется без
   потерь. Для отчётов предпочтителен SVG, для слайдов — PNG.
7. Таблица лучше для малого числа точных значений, поиска конкретного числа,
   доступности и копирования данных.
8. Корреляция описывает совместное изменение, а не причину. Поэтому в
   подписях пишут «связь», а не «влияние», и указывают возможные общие
   факторы.
