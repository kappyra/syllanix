# Решения к главе 14

Кортежи проще списков по набору операций, но именно на них строятся
распаковка и возврат нескольких значений. Проверяйте решения запуском.

## 1. Чтение кортежа {#sol-ch14-01}

```python exec
point = (10, 20)
print(point[0], point[-1], len(point))
print(5 in point)
```

```output
10 20 2
False
```

Первый элемент 10, последний 20, длина 2. Значение 5 в кортеж не входит.
Кортеж поддерживает те же операции чтения, что и любая
последовательность.

## 2. Кортеж из одного элемента {#sol-ch14-02}

```python exec
one = (7,)
print(type(one).__name__)
print(one[0])
print(len(one))
```

```output
tuple
7
1
```

`(7)` — это просто число 7 в скобках: скобки в арифметике меняют порядок
вычислений, но не создают кортеж. Кортеж создаёт запятая, поэтому
`(7,)` — кортеж из одного элемента.

## 3. Срезы кортежа {#sol-ch14-03}

```python exec
values = (1, 2, 3, 4, 5)
print(values[1:4])
print(values[::2])
print(values[-2:])
```

```output
(2, 3, 4)
(1, 3, 5)
(4, 5)
```

Срез копирует часть последовательности и сохраняет её тип: часть
кортежа — тоже кортеж. Поэтому результат выводится в круглых скобках.
Правая граница снова не включается.

## 4. Обойти неизменяемость {#sol-ch14-04}

```python exec
values = (1, 2, 3)
original = values
try:
    values[1] = 20
except TypeError as error:
    print("TypeError:", error)
values = values[:2] + (20,) + values[3:]
print(values)
print(original)
```

```output
TypeError: 'tuple' object does not support item assignment
(1, 2, 20)
(1, 2, 3)
```

Присваивание элементу невозможно. Но можно собрать новый кортеж из
частей старого: два первых элемента, новое значение и остаток. Имя
`values` теперь указывает на новый объект, а `original` — на исходный,
который не изменился.

## 5. Обмен значений {#sol-ch14-05}

```python exec
a, b = 1, 2
a, b = b, a
print(a, b)
```

```output
2 1
```

Справа сначала упаковывается кортеж `(b, a)`, то есть `(2, 1)`, и только
потом значения распаковываются в имена. Промежуточная переменная не
нужна, потому что старые значения сохранены в кортеже до присваивания.

## 6. Звёздочка {#sol-ch14-06}

```python exec
first, *middle, last = (1, 2, 3, 4, 5)
print(first)
print(middle)
print(last)
```

```output
1
[2, 3, 4]
5
```

`first` — целое число, `last` — целое число, а `middle` — список, потому
что звёздочка всегда собирает остаток в список. Длина остатка заранее
неизвестна, а список подходит для изменяемого набора.

## 7. Несколько значений из функции {#sol-ch14-07}

```python exec
def split_time(minutes):
    return minutes // 60, minutes % 60

hours, rest = split_time(150)
print(hours, "ч", rest, "мин")
print(split_time(75))
```

```output
2 ч 30 мин
(1, 15)
```

Функция возвращает кортеж из двух чисел. Первый вызов сразу распаковывает
его в имена, второй печатает кортеж целиком. Оба способа работы с
результатом допустимы.

## 8. Кортежи в цикле {#sol-ch14-08}

```python exec
pairs = [(1, "один"), (2, "два")]
for number, name in pairs:
    print(number, "-", name)
```

```output
1 - один
2 - два
```

В заголовке цикла происходит распаковка: каждый элемент списка — кортеж
из двух значений, и они сразу получают имена `number` и `name`.

## 9. Возврат двух значений {#sol-ch14-09}

```python exec
def min_and_max(a, b):
    if a < b:
        return a, b
    return b, a

small, large = min_and_max(9, 4)
print(small, large)
```

```output
4 9
```

Функция возвращает кортеж в порядке «меньшее, большее». Условие
выбирает порядок возврата, а вызывающий код распаковывает результат в
понятные имена.

## 10. Мини-задача: расстояние от начала {#sol-ch14-10}

```python exec
point = (3, 4)
x, y = point
distance_squared = x ** 2 + y ** 2
print(distance_squared)
```

```output
25
```

Кортеж выбран потому, что координата — фиксированная пара: её не нужно
дополнять или сортировать, а случайное изменение скорее дефект, чем
норма. Список позволил бы `point[0] = 100`, и координата перестала бы
означать точку.

## 11. Сумма произведений {#sol-ch14-11}

```python exec
def total(pairs):
    result = 0
    for left, right in pairs:
        result += left * right
    return result

print(total([(1, 2), (3, 4), (5, 6)]))
```

```output
44
```

Произведения: `1 * 2 = 2`, `3 * 4 = 12`, `5 * 6 = 30`; сумма 44.
Цикл распаковывает каждую пару, поэтому код обращается к значениям по
именам, а не по индексам.

## Ответы на вопросы для самопроверки

1. Кортеж неизменяем и не имеет методов изменения; список изменяем.
   Кортеж выбирают для фиксированных наборов, список — для данных,
   которые будут меняться.
2. Скобки не создают кортеж; его создаёт запятая. В `(5)` запятой нет,
   значит это число.
3. Неизменяемость запрещает менять объект после создания, поэтому его
   безопасно передавать в функции и хранить: никто не испортит данные.
4. Внутренний список остаётся изменяемым объектом: кортеж защищает только
   свои ссылки на элементы, а не содержимое этих элементов.
5. Упаковка создаёт кортеж из перечисленных значений, распаковка
   распределяет элементы кортежа по именам.
6. `a, b = b, a` — справа упаковывается кортеж, слева он распаковывается
   в обратном порядке.
7. Поднимается `ValueError` с указанием, сколько значений ожидалось и
   сколько получено.
