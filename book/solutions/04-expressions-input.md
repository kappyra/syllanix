# Решения к главе 4

Сначала попробуйте сами: решение полезно не тогда, когда вы его прочитали, а
когда сверили со своим. Запускайте код и проверяйте, совпадает ли вывод.

## 1. Порядок действий {#sol-ch04-01}

```python exec
print(8 + 2 * 5)
print((8 + 2) * 5)
print(2 ** 2 ** 3)
print(-2 ** 2)
print(17 % 5 + 17 // 5)
```

```output
18
50
256
-4
5
```

Разбор: умножение старше сложения, поэтому `8 + 10 = 18`. Скобки поднимают
сложение, и `10 * 5 = 50`. Возведение в степень связывает справа налево:
`2 ** (2 ** 3) = 2 ** 8 = 256`. Унарный минус слабее степени, поэтому
`-(2 ** 2) = -4`. Последняя строка: `2 + 3 = 5`.

## 2. Скобки по делу {#sol-ch04-02}

Средняя температура трёх дней:

```python exec
t1, t2, t3 = 10, 12, 14
print((t1 + t2 + t3) / 3)
print(t1 + t2 + t3 / 3)
```

```output
12.0
26.666666666666668
```

Без скобок деление выполнилось бы только для `t3`: `10 + 12 + 4.666…` даёт
`26.666666666666668`. Скобки обязательны: они задают, что суммируются все три
значения, и только потом сумма делится. Заодно пример напоминает, почему
`float` называют приближённым типом.

## 3. Прогнозирование сравнений {#sol-ch04-03}

```python exec
print(2 != 2)
print(2 <= 2)
print("a" < "b")
print("abc" == "abc ")
```

```output
False
True
True
False
```

`2 != 2` ложно, потому что числа равны. `2 <= 2` истинно: «меньше или равно»
включает равенство. `"a" < "b"` истинно по коду символа. Последняя строка
ложна: строки отличаются пробелом в конце, а `==` сравнивает значения целиком,
символ за символом.

## 4. Цепочка сравнений {#sol-ch04-04}

В реальной программе число приходит из `input` строкой и его нужно привести к
целому:

```python
raw = input("Число: ")
value = int(raw)
print(1 <= value <= 100)
```

Здесь и ниже для проверки подставим значения литералами: способ получения
числа на результат выражения не влияет.

```python exec
print(0, 1 <= 0 <= 100)
print(1, 1 <= 1 <= 100)
print(100, 1 <= 100 <= 100)
print(101, 1 <= 101 <= 100)
```

```output
0 False
1 True
100 True
101 False
```

Цепочка `1 <= value <= 100` истинна только для значений от 1 до 100
включительно. Обратите внимание на границы: `1` и `100` проходят, а `0` и
`101` — нет, потому что неравенства нестрогие.

## 5. Логические связки {#sol-ch04-05}

```python exec
a = 3
b = 7
c = 10
print(a < b and b < c)
print(a > b or b < c)
print(not a == 3)
```

```output
True
True
False
```

`a < b` и `b < c` истинны обе, значит `and` даёт `True`. Вторая связка: первое
сравнение ложно, второе истинно, для `or` этого достаточно. Третья: сравнение
`a == 3` истинно, а `not` его переворачивает. Обратите внимание, что `not`
применяется ко всему сравнению, а не к `a`: сравнение старше по приоритету.

## 6. Сокращённое вычисление {#sol-ch04-06}

```python exec
print("" or "нет данных")
print("есть" or "нет данных")
```

```output
нет данных
есть
```

`or` возвращает один из операндов. Первый операнд `""` — пустая строка, он
считается ложным, поэтому `or` переходит ко второму и возвращает `"нет
данных"`. Во втором случае первый операнд истинен, второй уже не нужен, и
возвращается `"есть"`. Это и есть сокращённое вычисление: правая часть
вычисляется только тогда, когда без неё не обойтись.

## 7. Исправление ошибки преобразования {#sol-ch04-07}

Тип ошибки — `TypeError`: `input` вернула строку, а `+` для строки и числа не
определён.

```python exec expect-error
age = "20"
print(age + 1)
```

```output
TypeError: can only concatenate str (not "int") to str
```

Исправление — явное преобразование:

```python exec
raw = "20"
age = int(raw)
print(age + 1)
```

```output
21
```

Если человек введёт `двадцать`, преобразование не сможет разобрать текст:

```python exec expect-error
print(int("двадцать"))
```

```output
ValueError: invalid literal for int() with base 10: 'двадцать'
```

Значит, корректная программа должна либо проверять ввод, либо сообщать об
ошибке понятным текстом. Обработку ошибок разберём в главе 10.

## 8. Расширенное присваивание {#sol-ch04-08}

```python exec
score = 100
score += 10
score *= 2
score -= 20
print(score)
```

```output
200
```

Вручную: `100 + 10 = 110`, `110 * 2 = 220`, `220 - 20 = 200`. Каждая строка
читает текущее значение имени, применяет операцию и записывает результат
обратно. Порядок строк важен: `*= 2` удваивает уже увеличенное значение.

## 9. Формат отчёта {#sol-ch04-09}

```python exec
name = "Анна"
score = 7
total = 10
print(f"{name}: {score} из {total} ({score / total * 100:.1f} %)")
```

```output
Анна: 7 из 10 (70.0 %)
```

Процент вычисляется как `7 / 10 * 100 = 70.0`; формат `:.1f` печатает ровно
один знак после точки. Пробел перед знаком `%` поставлен вручную: Python не
добавляет его сам.

## 10. Мини-задача: чек {#sol-ch04-10}

```python exec
raw_price = "250"
raw_count = "3"
raw_percent = "10"
price = int(raw_price)
count = int(raw_count)
percent = int(raw_percent)
total = price * count
discount = total * percent // 100
print(f"Товаров: {count}, сумма: {total}, скидка: {discount}, к оплате: {total - discount}")
```

```output
Товаров: 3, сумма: 750, скидка: 75, к оплате: 675
```

Порядок работы: три строки преобразуются в целые, сумма считается умножением,
скидка — целочисленным делением, чтобы остаться в рублях, итог — вычитанием.
Формат вывода задан f-строкой, поэтому числа подставляются без ручного `str`.

## Ответы на вопросы для самопроверки

1. Умножение старше сложения, поэтому `3 * 4` вычисляется первым; скобки
   `(2 + 3) * 4` меняют порядок и дают `20`.
2. Возведение в степень связывает справа налево: `2 ** (3 ** 2) = 2 ** 9 = 512`.
3. `==` сравнивает значения, `is` — идентичность объектов. За равенство
   значений отвечает `==`.
4. Логическое выражение — выражение со значением `True` или `False`; его тип —
   `bool`.
5. Потому что они возвращают один из операндов: так можно использовать их для
   выбора значения, а не только для получения признака.
6. Польза — не выполняется лишняя работа и возможна защита вида
   `значение or запасное`; опасность — побочный эффект справа может не
   выполниться.
7. `input` всегда возвращает `str`; поэтому перед арифметикой нужен
   `int` или `float`.
8. `int` отбрасывает дробную часть по направлению к нулю, `round` округляет к
   ближайшему целому (при половине — к чётному).
9. f-строка подставляет выражения прямо в текст, не требуя `str` и `+`, и
   позволяет задавать формат.
10. Python ожидает точку как десятичный разделитель, поэтому запятая в
    `float("3,5")` приводит к `ValueError`.
