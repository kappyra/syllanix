# Решения к главе 16

Множества проверяют понимание хеширования и порядка. Помните: печатать
множество напрямую не стоит — используйте `sorted`, чтобы вывод был
предсказуемым.

## 1. Уникальность {#sol-ch16-01}

```python exec
values = {10, 20, 20, 30}
print(len(values))
print(20 in values)
print(40 in values)
```

```output
3
True
False
```

В литерале четыре значения, но 20 повторяется, поэтому элементов три.
Проверка вхождения отвечает на вопрос о наличии: 20 есть, 40 нет.

## 2. Убрать повторы {#sol-ch16-02}

```python exec
print(sorted({1, 2, 2, 3, 3, 3}))
print(len({1, 2, 2, 3, 3, 3}))
```

```output
[1, 2, 3]
3
```

Множество хранит каждый элемент не более одного раза, поэтому повторы
исчезают ещё при создании. `sorted` возвращает список, чтобы порядок
вывода был определён.

## 3. Пересечение и объединение {#sol-ch16-03}

```python exec
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}
print(sorted(a & b))
print(sorted(a | b))
```

```output
[3, 4]
[1, 2, 3, 4, 5, 6]
```

Пересечение содержит общие элементы — 3 и 4. Объединение содержит все
элементы обоих множеств без повторов, поэтому 3 и 4 встречаются один раз.

## 4. Разности {#sol-ch16-04}

```python exec
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}
print(sorted(a - b))
print(sorted(b - a))
print(sorted(a ^ b))
```

```output
[1, 2]
[5, 6]
[1, 2, 5, 6]
```

`a - b` — то, что есть в `a`, но нет в `b`; `b - a` — наоборот. Порядок
операндов важен, поэтому результаты разные. Симметрическая разность
объединяет оба результата: элементы, которые есть ровно в одном
множестве.

## 5. Отношения множеств {#sol-ch16-05}

```python exec
print({1, 2} <= {1, 2, 3})
print({1, 2, 3} <= {1, 2, 3})
print({1, 2, 3} <= {1, 2})
```

```output
True
True
False
```

`<=` означает «является подмножеством или равно», поэтому множество
является подмножеством самого себя. Строгое `<` требует ещё и неравенства
множеств; для равных множеств оно даст `False`.

## 6. Изменение множества {#sol-ch16-06}

```python exec
values = {1, 2, 3}
values.add(4)
values.remove(2)
print(sorted(values))
values.discard(99)
print(sorted(values))
```

```output
[1, 3, 4]
[1, 3, 4]
```

`add` добавляет элемент, `remove` удаляет существующий. `discard` для
отсутствующего элемента ничего не делает: отсутствие значения
рассматривается как нормальная ситуация, а не ошибка.

## 7. Проверка вхождения {#sol-ch16-07}

```python exec
values = {1, 2, 3}
if 2 in values:
    print("есть")
else:
    print("нет")
```

```output
есть
```

Оператор `in` возвращает `True` или `False`; результат используется в
условии. Для отсутствующего значения проверка вернула бы `False`, и
выполнилась бы ветвь `else`.

## 8. Уникальные слова {#sol-ch16-08}

```python exec
words = ["кот", "пёс", "кот", "кот", "пёс"]
unique = set(words)
print(len(unique))
print(sorted(unique))
```

```output
2
['кот', 'пёс']
```

В списке пять слов, но различных среди них два. `set(words)` оставляет
по одному вхождению каждого слова; повторные `кот` и `пёс` исчезают.

## 9. Хешируемые элементы {#sol-ch16-09}

```python exec
try:
    {1, 2}.add([3, 4])
except TypeError as error:
    print("TypeError:", error)

fs = frozenset({1, 2})
print(len(fs))
print(1 in fs)
print(fs <= frozenset({1, 2, 3}))
```

```output
TypeError: cannot use 'list' as a set element (unhashable type: 'list')
2
True
True
```

Список изменяем, поэтому его нельзя хешировать по значению: после
изменения элемент перестал бы находиться по старому хешу, а контракт
«равные объекты имеют равный хеш» нарушился бы. Хеш по идентичности для
списка противоречил бы равенству по значению, поэтому список не хешируем.
`frozenset` неизменяем: его можно хранить, сравнивать и использовать в
операциях. Отношение включения для `frozenset` работает так же, как для
обычного множества.

## 10. Мини-задача: уникальные слова текста {#sol-ch16-10}

```python exec
def unique_words(text):
    return sorted(set(text.split()))

print(unique_words("раз два раз три два"))
```

```output
['два', 'раз', 'три']
```

Понадобились три операции: `split` разбил строку на слова, `set` убрал
повторы, `sorted` вернул определённый порядок и список. Слово «раз»
встречалось дважды, «два» — дважды, но в результате каждое встречается
один раз.

## Ответы на вопросы для самопроверки

1. Множество неупорядоченно, не хранит повторы и изменяемо; список
   упорядочен, допускает повторы и тоже изменяем.
2. Хеширование вычисляет по объекту целое число, по которому множество
   находит нужное место хранилища, не перебирая все элементы.
3. Хешируемы объекты с неизменяемым хешем: числа, строки, кортежи из
   хешируемых элементов. Список изменяем, поэтому не хешируем.
4. `discard` не поднимает ошибку при отсутствии элемента, `remove`
   поднимает `KeyError`.
5. Будет `TypeError`: множество не поддерживает индексацию, потому что не
   хранит порядок элементов.
6. `frozenset` неизменяем и хешируем; его можно положить в множество или
   использовать в качестве ключа.
7. Порядок зависит от внутреннего расположения элементов (хешей), а не от
   порядка добавления, и не является частью контракта типа.
