# Решения к главе 3

## 1. Типы значений {#sol-ch03-01}

```python exec
print(type(42))
print(type(3.0))
print(type("42"))
print(type(True))
print(type(None))
```

```output
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
<class 'NoneType'>
```

Обратите внимание: `3.0` — это `float`, даже если дробная часть нулевая; тип
определяется способом записи, а не математическим значением. `"42"` — строка,
а не число: кавычки меняют тип.

## 2. Присваивание и переприсваивание {#sol-ch03-02}

```python exec
a = 5
b = a
a = a + 1
print(a)
print(b)
```

```output
6
5
```

Пошагово: `a = 5` связывает `a` с объектом `5`; `b = a` связывает `b` с тем же
объектом; `a = a + 1` создаёт новый объект `6` и связывает с ним `a`, но `b`
по-прежнему указывает на `5`. Поэтому выводится `6`, затем `5`.

## 3. Присваивание не копирует {#sol-ch03-03}

`y = x` не копирует объект, потому что присваивание связывает имя с уже
существующим объектом. Проверить это можно оператором `is`: он истинен, если
оба имени указывают на один объект.

```python exec
x = "Python"
y = x
print(x is y)
```

```output
True
```

Если бы `y = x` создавало копию, `is` дало бы `False`. Обратите внимание: для
строк `is` может иногда давать `True` и без присваивания из-за внутреннего
кэширования, поэтому надёжнее демонстрировать на изменяемых объектах (например,
списках из главы 13).

## 4. Динамическая типизация {#sol-ch03-04}

Да, можно: имя не привязано к типу навсегда.

```python exec
x = 1
print(type(x))
x = "текст"
print(type(x))
```

```output
<class 'int'>
<class 'str'>
```

Противоречия нет: тип принадлежит объекту, а не имени. При первом присваивании
имя указывает на объект типа `int`, при втором — на объект типа `str`. Сами
объекты типы не меняют.

## 5. Идентичность и равенство {#sol-ch03-05}

```python exec
a = [1, 2]
b = [1, 2]
print(a == b)
print(a is b)
```

```output
True
False
```

`==` сравнивает значения: оба списка содержат `1` и `2`, поэтому `True`.
`is` сравнивает идентичность: это два разных объекта, поэтому `False`.
Если выполнить `b = a`, то `is` тоже станет `True`, потому что оба имени будут
указывать на один объект.

## 6. None {#sol-ch03-06}

`None` — единственный объект своего типа, созданный один раз. Поэтому проверка
`x is None` — это проверка идентичности с этим единственным объектом. Она
точна, быстра и не зависит от того, как тип `x` реализует сравнение через `==`
(свои классы могут переопределять `==`, и тогда `x == None` может вести себя
неожиданно). Принятое соглашение в Python — `x is None`; обратное условие —
`x is not None`.

## 7. Плавающая точка {#sol-ch03-07}

```python exec
print(0.1 + 0.2)
print(1 / 3)
```

```output
0.30000000000000004
0.3333333333333333
```

Числа `0.1` и `0.2` в двоичной системе с плавающей точкой записываются
приближённо (как `1/3` в десятичной записи). При сложении погрешности
накапливаются, и результат отличается от ближайшего к `0.3` представления.
Корректный способ сравнения — с допуском: проверять, что абсолютная разность
меньше, например, `1e-9`. Для денежных расчётов используют целые числа
(копейки) или `decimal.Decimal`.

## 8. Большие целые {#sol-ch03-08}

```python exec
print(2 ** 200)
print(2 ** 63 - 1)
```

```output
1606938044258990275541962092341162602522202993782792835301376
9223372036854775807
```

`2 ** 200` намного больше максимального знакового 64-битного целого
`2 ** 63 - 1`.
В Python переполнения нет: целые ограничены только памятью. В языках с
фиксированной разрядностью такое вычисление потребовало бы специальной
библиотеки.

## 9. Допустимые имена {#sol-ch03-09}

- `2x` — недопустимо: имя не может начинаться с цифры.
- `_x` — допустимо: подчёркивание может быть первым символом.
- `my-var` — недопустимо: дефис означает вычитание, а не часть имени.
- `total_price` — допустимо (и соответствует стилю `snake_case`).
- `class` — недопустимо: это зарезервированное слово языка.
- `итог` — допустимо: Python 3 разрешает буквы Unicode в именах. Однако в
  профессиональном коде латиница предпочтительна, чтобы имена были понятны
  инструментам и коллегам; кириллицу используйте осознанно.

## 10. Неизменяемость строк {#sol-ch03-10}

```python exec
s = "Python"
t = s
s = s + "!"
print(s)
print(t)
```

```output
Python!
Python
```

При выполнении `s = s + "!"` создаётся **новая** строка `"Python!"`, и имя `s`
привязывается к ней. Старая строка `"Python"`, на которую по-прежнему указывает
`t`, не изменилась. Строки неизменяемы: операции над ними возвращают новые
объекты.

## 11. Значение и объект {#sol-ch03-11}

«Значение 42» — это математическая величина, абстракция. «Объект типа `int`
со значением 42» — это конкретная сущность в памяти программы: у неё есть тип,
идентичность и состояние. В Python любое значение существует как объект,
поэтому второе описание точнее: тип и идентичность — реальные свойства,
которые можно наблюдать (`type`, `id`, `is`), и от них зависит поведение кода.

## 12. Один объект — два имени {#sol-ch03-12}

```python exec
x = "Python"
y = x
print(x is y)
y = "Другой текст"
print(x is y)
```

```output
True
False
```

Сначала `y = x` связывает `y` с тем же объектом, что и `x`, поэтому `is`
истинно. Затем `y = "Другой текст"` создаёт новый объект и связывает с ним
`y`; имя `x` продолжает указывать на прежний объект, поэтому теперь `is`
ложно.
