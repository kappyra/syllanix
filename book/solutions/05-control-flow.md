# Решения к главе 5

Проверяйте себя до чтения: полезно сначала записать свой ответ, а потом
сравнить. Особенно это касается задач на предсказание вывода — там ошибки
видны сразу.

## 1. Что напечатается {#sol-ch05-01}

```python exec
x = 12
if x > 10:
    print("больше десяти")
print("проверка окончена")
if x < 10:
    print("меньше десяти")
```

```output
больше десяти
проверка окончена
```

Первое условие истинно, поэтому его блок выполнился. Строка `проверка окончена`
стоит без отступа — она вне блока и печатается всегда. Второе условие ложно, и
его блок пропущен целиком.

## 2. Истинность значений {#sol-ch05-02}

```python exec
print(bool(0), bool("0"), bool(""))
print(bool(" "), bool(None), bool(-1), bool(0.0))
```

```output
False True False
True False True False
```

Только ноль, пустая строка и `None` ложны. Любая непустая строка истинна, даже
если состоит из пробела или изображает ноль. Число `-1` истинно, потому что
важен не знак, а отличие от нуля.

## 3. Исправление отступа {#sol-ch05-03}

Причина в том, что тело `if` не сдвинуто вправо: строка `print("доступ
разрешён")` стоит на том же уровне, что и условие, поэтому Python видит блок
без тела и не может разобрать программу. Исправление — добавить отступ в теле:

```python exec
age = 20
if age >= 18:
    print("доступ разрешён")
```

```output
доступ разрешён
```

Правильных вариантов отступа много: язык принимает и два, и три, и восемь
пробелов, если они одинаковы во всём блоке. Неправильным был бы отступ,
меньший или равный отступу условия, а также смешение табуляции и пробелов в
одном блоке. PEP 8 рекомендует четыре пробела, но это требование стиля, а не
языка.

## 4. Порядок ветвей {#sol-ch05-04}

```python exec
grade = 75
if grade >= 60:
    print("удовлетворительно")
elif grade >= 90:
    print("отлично")
elif grade >= 75:
    print("хорошо")
```

```output
удовлетворительно
```

Первое условие `grade >= 60` истинно для любого значения от 60 и выше, поэтому
до остальных ветвей очередь не доходит. Исправленный порядок — от строгого
условия к мягкому:

```python exec
grade = 75
if grade >= 90:
    print("отлично")
elif grade >= 75:
    print("хорошо")
elif grade >= 60:
    print("удовлетворительно")
else:
    print("неудовлетворительно")
```

```output
хорошо
```

## 5. Три случая {#sol-ch05-05}

```python exec
n = 7
if n > 0:
    print("положительное")
elif n < 0:
    print("отрицательное")
else:
    print("ноль")

n = -3
if n > 0:
    print("положительное")
elif n < 0:
    print("отрицательное")
else:
    print("ноль")

n = 0
if n > 0:
    print("положительное")
elif n < 0:
    print("отрицательное")
else:
    print("ноль")
```

```output
положительное
отрицательное
ноль
```

Три случая не пересекаются, поэтому цепочка `elif` подходит идеально. Обратите
внимание: `n = 0` не попадает ни в первое, ни во второе условие, и работает
ветвь `else`.

## 6. Плоская форма {#sol-ch05-06}

```python exec
age = 25
if age >= 18 and age <= 65:
    print("рабочий возраст")
```

```output
рабочий возраст
```

Оба условия соединены через `and`, вложенность исчезла. Та же проверка
записывается цепочкой сравнений из главы 4, и это самый читаемый вариант:

```python exec
age = 25
if 18 <= age <= 65:
    print("рабочий возраст")
```

```output
рабочий возраст
```

Эквивалентность сохраняется, потому что вложенное условие проверялось только
после истинности внешнего, а `and` устроен так же: второй операнд вычисляется,
только если первый истинен.

## 7. Условное выражение {#sol-ch05-07}

```python exec
limit = 100
message = "большой лимит" if limit > 50 else "маленький лимит"
print(f"Сообщение: {message}")
```

```output
Сообщение: большой лимит
```

Слева от `if` стоит значение для истинного случая, справа от `else` — для
ложного. Условие оказалось посередине, и это нормально: у условного выражения
свой порядок частей.

## 8. Ошибка с одним знаком {#sol-ch05-08}

Одиночное `=` — это присваивание, оно связывает имя со значением, но не даёт
того логического результата, которого ждёт `if`. В условии нужно сравнение:

```python exec
x = 5
if x == 5:
    print("пять")
```

```output
пять
```

`x = 5` меняет значение имени, `x == 5` задаёт вопрос «равно ли?» и возвращает
`True` или `False`. Python не разрешает присваивание в условии, поэтому
перепутать знаки можно только в одну сторону — и это защищает от целого класса
ошибок.

## 9. Билеты по возрасту {#sol-ch05-09}

Возраст 5 лет — бесплатно:

```python exec
age = int("5")
if age < 6:
    price = 0
elif age < 18:
    price = 300
elif age < 65:
    price = 600
else:
    price = 200
print(f"Возраст {age}: {price} рублей")
```

```output
Возраст 5: 0 рублей
```

Возраст 12 лет:

```python exec
age = int("12")
if age < 6:
    price = 0
elif age < 18:
    price = 300
elif age < 65:
    price = 600
else:
    price = 200
print(f"Возраст {age}: {price} рублей")
```

```output
Возраст 12: 300 рублей
```

Возраст 30 лет:

```python exec
age = int("30")
if age < 6:
    price = 0

    price = 300
elif age < 65:
    price = 600
else:
    price = 200
print(f"Возраст {age}: {price} рублей")
```

```output
Возраст 30: 600 рублей
```

Возраст 70 лет:

```python exec
age = int("70")
if age < 6:
    price = 0
elif age < 18:
    price = 300
elif age < 65:
    price = 600
else:
    price = 200
print(f"Возраст {age}: {price} рублей")
```

```output
Возраст 70: 200 рублей
```

Порядок условий здесь от младшего возраста к старшему, и каждое следующее
условие можно писать без нижней границы: до него доходят только те значения,
которые не подошли предыдущим. Такая запись короче, чем четыре независимых
проверки с двумя границами в каждой.

## 10. Два if или elif {#sol-ch05-10}

Первый вариант с двумя независимыми `if` печатает обе строки, потому что
проверяются оба условия:

```python exec
x = 150
if x > 100:
    print("больше ста")
if x > 50:
    print("больше пятидесяти")
```

```output
больше ста
больше пятидесяти
```

Второй вариант с `elif` печатает только первую строку: после истинной ветви
цепочка завершается.

```python exec
x = 150
if x > 100:
    print("больше ста")
elif x > 50:
    print("больше пятидесяти")
```

```output
больше ста
```

Цепочка `elif` уместна и читается лучше, когда варианты взаимоисключающие и
нужен ровно один ответ: категория товара, оценка, тариф. Независимые `if`
уместны, когда проверки не связаны между собой и каждая может сработать сама
по себе. Обязательной цепочка не бывает: тот же выбор можно выразить через
`if` с `return` или вложенный `else`.

## Ответы на вопросы для самопроверки

1. Ложны `0`, `0.0`, `""`, `None`, `False` и пустые коллекции. `"0"` — непустая
   строка, поэтому истинна: правило смотрит на пустоту, а не на смысл текста.
2. Условие — выражение, чей результат трактуется по правилу истинности; оно
   определяет, какая ветвь будет исполнена.
3. Блок — группа инструкций, исполняемых вместе; его границы задаёт отступ.
4. Потому что отступ определяет структуру программы: от него зависит, какая
   инструкция относится к какому блоку.
5. Независимые `if` проверяются все, цепочка `elif` — только до первого
   истинного условия.
6. Потому что до более строгого условия очередь может не дойти: его перекрывает
   более мягкое, стоящее выше.
7. Условное выражение выбирает значение, инструкция `if` выполняет действия.
8. `IndentationError` возникает при неверном отступе внутри блока, `TabError` —
   при смешении табуляции и пробелов.
