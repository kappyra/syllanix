# Решения к главе 15

Строки прощают многое, но кодировки и регистр умеют удивлять. Проверяйте
решения запуском и смотрите на `repr`, когда результат неочевиден.

## 1. Строка как последовательность {#sol-ch15-01}

```python exec
text = "Python"
print(len(text))
print(text[0], text[-1])
print(text[2:5])
print("th" in text)
```

```output
6
P n
tho
True
```

Длина 6, первый символ `P`, последний `n`. Срез `text[2:5]` берёт
символы с индексами 2, 3, 4 — это `t`, `h`, `o`; правая граница не
включается. Подстрока `"th"` входит в строку.

## 2. Символы и байты {#sol-ch15-02}

```python exec
text = "Ёж"
print(len(text))
print(ord(text[0]), ord(text[1]))
print(text.encode("utf-8"))
```

```output
2
1025 1078
b'\xd0\x81\xd0\xb6'
```

Строка состоит из двух символов, поэтому `len` равно 2. В UTF-8 каждая
кириллическая буква кодируется двумя байтами, итого четыре байта.
Кодовые точки при этом остаются двумя: 1025 и 1078. Длина строки и длина
байтов — разные величины.

## 3. Escape-последовательности {#sol-ch15-03}

```python exec
print("a\nb".count("\n") + 1)
print(len("a\nb"))
print(repr("a\tb"))
```

```output
2
3
'a\tb'
```

`print("a\nb")` выводит две строки: перевод строки действительно разрывает
вывод. Длина строки при этом равна трём, потому что `\n` — один символ, а
не два. `repr` показывает служебные символы в явном виде: `\t`
отображается как escape-последовательность.

## 4. Чистка текста {#sol-ch15-04}

```python exec
text = "  Hello, World!  "
print(repr(text.strip()))
print(text.strip().lower())
print(text.strip().replace("World", "Python"))
```

```output
'Hello, World!'
hello, world!
Hello, Python!
```

Методы можно вызывать цепочкой: `strip` возвращает новую строку, у неё
вызывается `lower`. Исходная строка не меняется, поэтому цепочка строит
новые объекты на каждом шаге.

## 5. Разбор предложения {#sol-ch15-05}

```python exec
sentence = "яблоко банан груша"
parts = sentence.split()
print(parts)
print(sorted(parts))
```

```output
['яблоко', 'банан', 'груша']
['банан', 'груша', 'яблоко']
```

`split()` без аргумента делит по пробелам. Сортировка идёт по кодовым
точкам: `б` (1073) меньше `г` (1075), а `я` (1103) больше обеих. Для
русских слов без буквы `ё` такой порядок совпадает с алфавитным.

## 6. Нормализация имени {#sol-ch15-06}

```python exec
def normalize(name):
    return name.strip().lower()

print(repr(normalize("  Alice ")))
print(repr(normalize("BOB")))
```

```output
'alice'
'bob'
```

Функция возвращает новую строку: `strip` убирает пробелы, `lower`
приводит регистр. `repr` в проверке показывает, что лишних символов не
осталось.

## 7. Сравнение и регистр {#sol-ch15-07}

```python exec
print("Python" < "python")
print("banana".count("a"))
print("banana".find("a"))
```

```output
True
3
1
```

`"Python" < "python"` истинно, потому что заглавная `P` имеет код 80, а
строчная `p` — 112. Буква `a` встречается в `banana` три раза, первое
вхождение стоит на позиции 1 (второй символ). `find` возвращает индекс, а
не количество.

## 8. Слова и длины {#sol-ch15-08}

```python exec
for word in "раз два три".split():
    print(word, len(word))
```

```output
раз 3
два 3
три 3
```

`split()` возвращает список слов, перебор идёт по нему как по любой
последовательности. Для каждого слова вычисляется длина в символах.

## 9. Форматирование {#sol-ch15-09}

```python exec
print(f"{3.14159:.2f}")
print(f"{42:05d}")
print(f"{'ok':^10}|")
```

```output
3.14
00042
    ok    |
```

`.2f` оставляет два знака после запятой и округляет. `05d` задаёт ширину
5 и заполнение нулями слева. `^10` центрирует строку в поле шириной 10;
вертикальная черта показывает границу поля.

## 10. Мини-задача: инициалы {#sol-ch15-10}

```python exec
def initials(full_name):
    parts = full_name.split()
    result = ""
    for part in parts:
        result += part[0].upper()
    return result

print(initials("иван петров"))
print(initials("анна сергеевна сидорова"))
```

```output
ИП
АСС
```

Понадобились `split` для разбиения на слова, индексация `[0]` для первого
символа, `upper` для регистра и соединение строк через `+=`. Пустая
строка `result` служит начальным накопителем; это тот же приём, что
накопление суммы в цикле.

## Ответы на вопросы для самопроверки

1. Строка неизменяема: после создания её нельзя изменить, поэтому методы
   возвращают новую строку, а не правят исходную.
2. Кодовая точка — номер символа в стандарте Unicode; байт — единица
   хранения. `len` считает кодовые точки (символы), а не байты.
3. Кодировка задаёт правило перевода строки в байты и обратно; при
   неверной кодировке получается ошибка декодирования или искажённый
   текст.
4. В «сырой» строке обратная косая черта не начинает
   escape-последовательность: `r"\n"` — два символа.
5. `split` возвращает список строк; `join` принимает последовательность
   строк и вызывает его у разделителя.
6. Сравнение идёт по кодовым точкам: `Ё` имеет код 1025, `А` — 1040,
   поэтому `Ё` меньше, хотя в алфавите стоит позже.
7. `>12` — выравнивание по правому краю в поле 12, `,` — разделитель
   тысяч, `.2f` — два знака после запятой.
