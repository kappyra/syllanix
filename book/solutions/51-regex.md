# Решения к главе 51

Регулярное выражение легко написать и трудно прочитать. Поэтому в решениях
ниже шаблоны короткие, а рядом с ними — объяснение, что именно каждая часть
шаблона делает.

## 1. Прогнозирование вывода {#sol-ch51-01}

```python exec
import re

print(re.findall(r"\d+", "a1 b22 c333"))
print(re.findall(r"\d", "a1 b22 c333"))
print(re.findall(r"([a-z])\d+", "a1 b22 c333"))
```

```output
['1', '22', '333']
['1', '2', '2', '3', '3', '3']
['a', 'b', 'c']
```

Первая строка собирает целые числа из цифр подряд: `1`, `22`, `333`. Вторая
берёт каждую цифру отдельно. Третья содержит группу, поэтому `findall`
возвращает только содержимое группы — буквы перед числами, а не сами пары.

## 2. Первый шаблон {#sol-ch51-02}

```python exec
import re

text = "температура -5, потом 12, затем -3"
print(re.findall(r"-?\d+", text))
```

```output
['-5', '12', '-3']
```

`-?` означает «необязательный минус», `\d+` — одну или несколько цифр.
Вместе получается число с сохранённым знаком. Если бы минус не был
необязательным, положительное `12` не нашлось бы.

## 3. Классы символов {#sol-ch51-03}

```python exec
import re

text = "заказ A12, B7, C345"
print(re.findall(r"[A-Z]\d+", text))
print(re.findall(r"[A-Z](\d+)", text))
```

```output
['A12', 'B7', 'C345']
['12', '7', '345']
```

Первый шаблон возвращает коды целиком: заглавная буква и цифры. Второй
заключает цифры в группу, и `findall` отдаёт только её содержимое — числовые
части. Это ожидаемое поведение, а не сюрприз: при группах `findall` отдаёт
группы.

## 4. Проверка формата {#sol-ch51-04}

```python exec
import re

pattern = re.compile(r"[A-Z]{2}\d{4}")
for code in ["AB1234", "A1234", "ab1234"]:
    print(code, bool(pattern.fullmatch(code)))
```

```output
AB1234 True
A1234 False
ab1234 False
```

`[A-Z]{2}` требует ровно две заглавные латинские буквы, `\d{4}` — ровно
четыре цифры. `A1234` отсекается, потому что буква одна; `ab1234` — потому
что буквы строчные. `fullmatch` требует совпадения со всей строкой, поэтому
«хвост» или «голова» из лишних символов не пройдут.

## 5. Группы и дата {#sol-ch51-05}

```python exec
import re

text = "срок: 2026-05-17"
pattern = r"(?P<year>\d{4})-(?P<month>\d{2})-(?P<day>\d{2})"
match = re.search(pattern, text)
parts = match.groupdict()
print(f"{parts['day']}.{parts['month']}.{parts['year']}")
```

```output
17.05.2026
```

`groupdict()` возвращает словарь с именами групп, и дальше с ним работают как
с обычным словарём. Именованные группы удобнее номеров: при изменении шаблона
не приходится пересчитывать позиции.

## 6. Жадность {#sol-ch51-06}

```python exec
import re

text = "<a>раз</a><b>два</b>"
print(re.findall(r"<.+>", text))
print(re.findall(r"<.+?>", text))
```

```output
['<a>раз</a><b>два</b>']
['<a>', '</a>', '<b>', '</b>']
```

Жадный `.+` тянется до последнего `>` в строке, поэтому всё содержимое
оказалось внутри одного совпадения. Ленивый `.+?` останавливается на первом
подходящем `>`, и теги находятся по отдельности. Если шаблон «съел лишнее»,
причина почти всегда в жадности.

## 7. Флаги {#sol-ch51-07}

```python exec
import re

text = "Error: раз\nERROR: два\nerror: три\nшаг 1\nшаг 2"
print(re.findall(r"error", text, re.IGNORECASE))
print(re.findall(r"^шаг", text, re.MULTILINE))
```

```output
['Error', 'ERROR', 'error']
['шаг', 'шаг']
```

`IGNORECASE` позволяет шаблону `error` совпадать с любым регистром, но
возвращается исходный текст, поэтому все три варианта разные. `MULTILINE`
делает `^` началом каждой строки, а не только всего текста, поэтому оба
«шаг» найдены.

## 8. Замена по шаблону {#sol-ch51-08}

```python exec
import re

text = "12-03-2025, 05-11-2024"
print(re.sub(r"(\d{2})-(\d{2})-(\d{4})", r"\3.\2.\1", text))
```

```output
2025.03.12, 2024.11.05
```

В строке замены `\1`, `\2`, `\3` означают содержимое групп: год, месяц и
день. Шаблон замены переставляет их в нужном порядке. Обратите внимание на
`r` перед строкой замены: без него `\3` мог бы быть прочитан как служебная
последовательность.

## 9. Мини-проект: разбор журнала {#sol-ch51-09}

```python exec
import re

text = (
    "2026-05-17 12:00:00 ERROR база недоступна\n"
    "2026-05-17 12:00:05 INFO старт\n"
    "2026-05-17 12:00:09 ERROR сеть"
)
pattern = re.compile(
    r"^(?P<date>\d{4}-\d{2}-\d{2}) "
    r"(?P<time>\d{2}:\d{2}:\d{2}) "
    r"(?P<level>[A-Z]+) "
    r"(?P<message>.+)$",
    re.MULTILINE,
)


def parse_log(text):
    entries = []
    for match in pattern.finditer(text):
        entries.append(
            {
                "date": match.group("date"),
                "level": match.group("level"),
                "message": match.group("message"),
            }
        )
    return entries


entries = parse_log(text)
print(entries)
counts = {}
for entry in entries:
    counts[entry["level"]] = counts.get(entry["level"], 0) + 1
print(counts)
```

```output
[{'date': '2026-05-17', 'level': 'ERROR', 'message': 'база недоступна'}, {'date': '2026-05-17', 'level': 'INFO', 'message': 'старт'}, {'date': '2026-05-17', 'level': 'ERROR', 'message': 'сеть'}]
{'ERROR': 2, 'INFO': 1}
```

`MULTILINE` нужен, чтобы якоря `^` и `$` работали для каждой строки журнала,
а `finditer` выдаёт совпадения по одному. Сообщение может содержать пробелы,
поэтому оно захватывается целиком группой `message`, а не делится по
пробелам. Подсчёт уровней собран на словаре без `Counter`: словари разобраны
в главе 17, а специализированный счётчик — в главе о стандартной библиотеке.

## 10. Когда шаблон лишний {#sol-ch51-10}

- найти строки файла, начинающиеся с `DEBUG`, — шаблон не нужен:
  у строки есть метод `startswith`;
- проверить, что строка состоит только из цифр, — шаблон не нужен:
  `str.isdigit()` проще и быстрее;
- извлечь ссылки `https://…` — шаблон нужен: важна структура и переменная
  длина;
- разобрать JSON и получить поле — шаблон опасен: нужен модуль `json`,
  который учитывает вложенность и экранирование.

Пример «шаблон нужен»:

```python exec
import re

text = "см. https://example.com и https://docs.python.org/3/"
print(re.findall(r"https://[^\s]+", text))
```

```output
['https://example.com', 'https://docs.python.org/3/']
```

Класс `[^\s]+` читается как «любые символы, кроме пробельных», поэтому ссылка
заканчивается на пробеле и не захватывает следующее слово.

Пример «шаблон не нужен»:

```python exec
print("12345".isdigit())
print("12a45".isdigit())
```

```output
True
False
```

`isdigit` сразу отвечает на нужный вопрос. Писать ради этого регулярное
выражение — лишняя сложность: читателю пришлось бы разбирать шаблон, чтобы
понять простую проверку.

## Ответы на вопросы для самопроверки

1. `str.find` ищет точную подстроку; регулярное выражение описывает форму и
   находит множество вариантов, соответствующих шаблону.
2. Сырая строка не даёт обратной косой черте начинать escape-последовательность,
   поэтому `r"\d"` — это два символа, а не один служебный.
3. `\d` — цифра, `\w` — буква, цифра или подчёркивание, `\s` — пробельный
   символ; заглавные `\D`, `\W`, `\S` означают дополнение.
4. `match` проверяет совпадение с начала строки, `search` ищет в любом месте,
   `fullmatch` требует совпадения со всей строкой — его применяют для
   проверки формата.
5. Часть шаблона заключают в скобки, значение читают через `group(1)` или
   `group("имя")`; именованные группы задаются как `(?P<name>…)`.
6. Жадный квантификатор берёт максимум, ленивый — минимум; ленивый получают,
   добавив `?` после квантификатора (`*?`, `+?`).
7. `IGNORECASE` игнорирует регистр, `MULTILINE` делает `^` и `$` якорями
   строк, `DOTALL` разрешает точке совпадать с переводом строки, `VERBOSE`
   разрешает пробелы и комментарии в шаблоне.
8. Если в шаблоне есть захватывающие группы, `findall` возвращает их
   содержимое, а не всё совпадение.
9. HTML вложенный, а регулярное выражение не отслеживает вложенность надёжно;
   для разметки нужен парсер.
