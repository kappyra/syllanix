# Решения к главе 13

Проверяйте ответы запуском: у срезов и границ индексов много
исключений, которые проще увидеть, чем запомнить.

## 1. Чтение списка {#sol-ch13-01}

```python exec
numbers = [5, 10, 15, 20, 25]
print(numbers[0], numbers[-1], len(numbers))
print(numbers[2])
print(20 in numbers)
```

```output
5 25 5
15
True
```

Первый элемент — 5, последний — 25, длина — 5. Элемент с индексом 2 —
третий по счёту, это 15. Значение 20 входит в список.

## 2. Изменение элементов {#sol-ch13-02}

```python exec
numbers = [1, 2, 3]
numbers.append(4)
numbers.insert(0, 0)
numbers[2] = 20
print(numbers)
```

```output
[0, 1, 20, 3, 4]
```

После `insert(0, 0)` все элементы сдвинулись вправо: бывший первый
элемент стал вторым. Поэтому индекс 2 теперь указывает на значение 2 (бывший
второй элемент), и замена `numbers[2] = 20` меняет именно его, а не 1. Порядок
операций важен: если бы замена шла до вставки, результат был бы другим.

## 3. Срезы {#sol-ch13-03}

```python exec
letters = ["a", "b", "c", "d", "e", "f"]
print(letters[2:5])
print(letters[-3:])
print(letters[::3])
```

```output
['c', 'd', 'e']
['d', 'e', 'f']
['a', 'd']
```

`letters[2:5]` берёт индексы 2, 3, 4; индекс 5 не включается.
`letters[-3:]` начинает с третьего элемента от конца, то есть с `d`, и
идёт до конца. `letters[::3]` берёт каждый третий элемент, начиная с
нулевого: `a`, `d`.

## 4. Сортировка {#sol-ch13-04}

```python exec
numbers = [4, 1, 3, 2]
numbers.sort()
print(numbers)
print(sorted(numbers, reverse=True))
print(numbers)
```

```output
[1, 2, 3, 4]
[4, 3, 2, 1]
[1, 2, 3, 4]
```

`sort` меняет список на месте, поэтому после него `numbers` уже
отсортирован. `sorted(numbers, reverse=True)` возвращает новый список в
обратном порядке и не трогает исходный. Третья строка подтверждает, что
`numbers` остался отсортированным по возрастанию.

## 5. Удаление {#sol-ch13-05}

```python exec
numbers = [10, 20, 30, 40, 50]
del numbers[2]
del numbers[::2]
print(numbers)
```

```output
[20, 50]
```

После первой `del` список стал `[10, 20, 40, 50]`. Срез `[::2]` описывает
элементы с индексами 0 и 2 — это 10 и 40; `del` удаляет их оба. Остаются
20 и 50.

## 6. Работа со словами {#sol-ch13-06}

```python exec
words = ["яблоко", "груша", "банан"]
words.append("слива")
words.sort()
words.pop(0)
print(words)
```

```output
['груша', 'слива', 'яблоко']
```

После добавления список содержит четыре слова. `sort` расставляет их по
кодовым точкам: банан, груша, слива, яблоко. `pop(0)` удаляет первое
слово, остаётся три.

## 7. Ловушка append {#sol-ch13-07}

```python exec
numbers = [10, 20, 30]
result = numbers.append(40)
print(result)
print(numbers)
```

```output
None
[10, 20, 30, 40]
```

`append` меняет список, но возвращает `None`. Поэтому `result` равно
`None`, а список всё равно изменился. Опасность в том, что запись
`numbers = numbers.append(40)` потеряет список: имя получит `None`, и все
дальнейшие операции с ним приведут к `AttributeError`.

## 8. Границы среза {#sol-ch13-08}

```python exec
numbers = [10, 20, 30]
print(numbers[1:100])
print(numbers[5:9])
```

```output
[20, 30]
[]
```

Срез описывает диапазон позиций, поэтому слишком большой конец
воспринимается как «до конца списка», а начало за пределами списка даёт
пустой срез. Обращение по индексу работает иначе: оно запрашивает
конкретный элемент, и если его нет — поднимается `IndexError`.

## 9. Извлечение в цикле {#sol-ch13-09}

```python exec
numbers = [10, 20, 30, 40]
total = 0
while numbers:
    total += numbers.pop()
print(total)
```

```output
100
```

`while numbers:` истинно, пока список не пуст. Каждый шаг извлекает
последний элемент и прибавляет его к сумме; список сокращается, поэтому
цикл завершается. Если забыть про `pop`, условие останется истинным
навсегда — получится бесконечный цикл.

## 10. Фильтр чётных {#sol-ch13-10}

```python exec
def evens(numbers):
    result = []
    for number in numbers:
        if number % 2 == 0:
            result.append(number)
    return result

print(evens([1, 2, 4, 5, 6, 7]))
```

```output
[2, 4, 6]
```

Функция создаёт новый список и наполняет его подходящими элементами.
Исходный список не меняется — это правильный стиль для фильтрации:
вызывающий код получает результат, не теряя входные данные.

## 11. Сортировка без изменения оригинала {#sol-ch13-11}

```python exec
def normalize(numbers):
    result = numbers[:]
    result.sort()
    return result

original = [3, 1, 2]
ordered = normalize(original)
print(original)
print(ordered)
```

```output
[3, 1, 2]
[1, 2, 3]
```

Срез `numbers[:]` создаёт копию, поэтому сортировка копии не затрагивает
оригинал. Того же результата можно добиться функцией `sorted(numbers)`,
которая сразу возвращает новый отсортированный список.

## Ответы на вопросы для самопроверки

1. Список изменяемый, его можно дополнять и править; `range` задаёт
   фиксированную последовательность и используется для перебора.
2. Нумерация с конца — это отрицательные смещения: `-1` означает
   последний элемент, а `-0` совпал бы с первым.
3. `numbers[3]` возвращает элемент; `numbers[3:4]` возвращает список из
   одного элемента и не поднимает ошибку при выходе за границу.
4. Python следует правилу: метод, меняющий объект на месте, возвращает
   `None`. Присваивание результата теряет список.
5. `remove(x)` принимает значение, ничего не возвращает; `pop(i)`
   принимает индекс и возвращает удалённый элемент.
6. `sort` сортирует на месте и возвращает `None`, `sorted` возвращает
   новый список и оставляет исходный порядок.
7. Срез создаёт новый объект, поэтому его изменения не видны в исходном
   списке; присваивание по индексу меняет сам объект.
