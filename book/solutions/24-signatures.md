# Решения к главе 24

Решения отделены от условий: сначала попробуйте сами, затем сверьтесь.
В каждом решении важен не только ответ, но и объяснение, почему получилось
именно так.

## 1. Прогноз вывода {#sol-ch24-01}

```python exec
def f(*args, **kwargs):
    return len(args), len(kwargs)

print(f(1, 2, 3))
print(f(a=1))
print(f(1, b=2))
```

```output
(3, 0)
(0, 1)
(1, 1)
```

В первом вызове три позиционных аргумента попали в `args`, именованных нет.
Во втором наоборот: позиционных ноль, один именованный. Третий вызов
смешанный: одно значение по месту и одно по имени. Функция возвращает кортеж
из двух чисел, поэтому каждая строка выглядит как пара в скобках.

## 2. Сборка строки с keyword-only параметром {#sol-ch24-02}

```python exec
def join_words(*words, sep=" "):
    return sep.join(words)

print(join_words("a", "b"))
print(join_words("a", "b", sep="-"))
print(repr(join_words()))
```

```output
a b
a-b
''
```

Параметр `sep` стоит после `*words`, поэтому он только именованный:
позиционная передача `join_words("a", "b", "-")` попала бы в `*words` как
третье слово. Пустой вызов даёт пустой кортеж слов и пустую строку — `join`
от пустой последовательности возвращает `''`. Функция `repr` показывает
кавычки, иначе пустую строку было бы не отличить от отсутствия вывода.

## 3. Исправление сигнатуры {#sol-ch24-03}

Ошибка возникает потому, что функция объявляет два параметра, а вызов
передаёт три позиционных аргумента: лишнему некуда деться. Первое
исправление — явный третий параметр со значением по умолчанию:

```python exec
def area(width, height, depth=1):
    return width * height * depth

print(area(2, 3, 4))
```

```output
24
```

Второе исправление — сборный параметр, если число измерений действительно
переменное:

```python exec
def area_all(*sizes):
    result = 1
    for size in sizes:
        result *= size
    return result

print(area_all(2, 3, 4))
```

```output
24
```

Первый вариант точнее описывает контракт: видно, что размеров три, а глубина
необязательна. Второй вариант гибче, но допускает вызов с одним числом, что
для площади уже сомнительно. Выбор зависит от того, что функция обещает.

## 4. Распаковка при вызове {#sol-ch24-04}

```python exec
def box(width, height, depth=1):
    return width * height * depth

coords = [2, 3]
opts = {"depth": 5}

print(box(*coords, **opts))
print(box(*[2, 3], depth=5))
print(box(2, 3, **opts))
```

```output
30
30
30
```

Все три вызова равносильны, но показывают разные комбинации: обе распаковки
вместе, распаковка списка и именованный аргумент, обычные аргументы и
распаковка словаря. Четвёртый вариант — `box(*coords, depth=opts["depth"])` —
тоже корректен. Главное правило: после распаковки вызов проверяется по той
же сигнатуре, что и без неё.

## 5. Сумма произвольного числа значений {#sol-ch24-05}

```python exec
def sum_all(*numbers):
    return sum(numbers)

print(sum_all())
print(sum_all(7))
print(sum_all(1, 2, 3))
print(sum_all(1.5, 2.5))
```

```output
0
7
6
4.0
```

`sum` от пустого кортежа даёт `0` — это её документированное поведение, а не
особенность сборного параметра. Одно значение возвращается без изменений.
Сумма целых остаётся целой, а как только появляется число с дробной частью,
результат становится `4.0`: арифметика смешанных типов даёт `float`.

## 6. Смешанная сигнатура {#sol-ch24-06}

```python exec
def describe(name, /, *tags, **meta):
    print("имя:", name)
    print("метки:", tags)
    print("остальное:", meta)

describe("Аня", "новый", "VIP", city="Москва")
```

```output
имя: Аня
метки: ('новый', 'VIP')
остальное: {'city': 'Москва'}
```

Имя передано по месту, две метки тоже, город — по имени. Имя по ключу
невозможно: маркер `/` запрещает передавать `name` как именованный аргумент.
А вызов вида `describe("Аня", tag1="новый")` возможен, но метка попадёт в
`meta`, а не в `tags`: `*tags` собирает только позиционные аргументы. Это
источник тихой ошибки — функция не заметит, что метку передали не туда.
Проверим первый запрет:

```python exec expect-error
def describe(name, /, *tags, **meta):
    return None

print(describe(name="Аня"))
```

```output
TypeError: describe() missing 1 required positional argument: 'name'
```

## 7. Анализ: чем плоха универсальная функция {#sol-ch24-07}

Универсальная версия принимает опечатку молча и складывает её в словарь:

```python exec
def send(*args, **kwargs):
    print("принято:", args, kwargs)

send("Аня", "привет", urgentt=True)
```

```output
принято: ('Аня', 'привет') {'urgentt': True}
```

Функция «сработала», но флаг `urgentt` никто не прочитает: намерение
отправить срочное сообщение потеряно без единого сообщения об ошибке.
Явная сигнатура ведёт себя иначе:

```python exec expect-error
def send(recipient, text, *, urgent=False):
    print("отправлено:", recipient, text, urgent)

send("Аня", "привет", urgentt=True)
```

```output
TypeError: send() got an unexpected keyword argument 'urgentt'. Did you mean 'urgent'?
```

Python не только сообщает об ошибке, но и подсказывает ближайшее имя.
Вывод: универсальная сигнатура уместна в обёртке, которая передаёт вызов
дальше, и неуместна там, где имена аргументов — часть контракта.

## 8. Только позиционный параметр {#sol-ch24-08}

```python exec
def divide(dividend, divisor, /):
    return dividend / divisor

print(divide(7, 2))
```

```output
3.5
```

Передача по имени запрещена:

```python exec expect-error
def divide(dividend, divisor, /):
    return dividend / divisor

print(divide(dividend=7, divisor=2))
```

```output
TypeError: divide() got some positional-only arguments passed as keyword arguments: 'dividend, divisor'
```

Такие параметры объявляют, когда имя внутреннее: автор оставляет за собой
право переименовать `dividend` в `a`, не ломая чужие вызовы. Второй мотив —
развести конфликт имён: если функция принимает `**kwargs`, параметр с именем
`name` иначе перехватывал бы одноимённый ключ.

## 9. Мини-проект: сборка адреса {#sol-ch24-09}

```python exec
def build_url(base, *segments, **query):
    path = "/".join([base, *segments])
    if not query:
        return path
    pairs = [f"{key}={value}" for key, value in query.items()]
    return path + "?" + "&".join(pairs)

print(build_url("https://example.com", "api", "users", page=1, limit=10))
print(build_url("https://example.com", "health"))
```

```output
https://example.com/api/users?page=1&limit=10
https://example.com/health
```

Сегменты пути собираются через `/`, параметры запроса — через `&`; порядок
параметров сохраняется в порядке передачи, потому что словарь помнит порядок
вставки. Если параметров нет, знак `?` не добавляется: пустой запрос выглядел
бы как `.../health?`. Это пример того, как сборные параметры делают интерфейс
коротким, а проверка `if not query` сохраняет корректный результат.

## 10. Форвардинг с отчётом {#sol-ch24-10}

```python exec
def trace(func, *args, **kwargs):
    print("функция:", func.__name__)
    print("аргументы:", args, kwargs)
    result = func(*args, **kwargs)
    print("результат:", result)
    return result

def mul(a, b):
    return a * b

print(trace(mul, 3, 4))
print(trace(mul, a=3, b=4))
```

```output
функция: mul
аргументы: (3, 4) {}
результат: 12
12
функция: mul
аргументы: () {'a': 3, 'b': 4}
результат: 12
12
```

Обёртка не разбирает аргументы: она печатает их как есть и передаёт дальше.
Поэтому работают оба способа вызова. Обратите внимание на две последние
строки каждого блока: сначала печатает сама обёртка, потом `print` во внешнем
коде печатает возвращённое значение. Именно так устроены декораторы из
главы 22, только там обёртка возвращается как новая функция.

## Ответы на вопросы для самопроверки

1. Параметр объявляется в `def` и получает значение при вызове; аргумент —
   это значение в вызове. В `def f(a)` слово `a` — параметр, в `f(5)` число
   `5` — аргумент.
2. `*args` даёт кортеж. Кортеж неизменяем, поэтому дополнить его на месте
   нельзя — можно только создать новое значение.
3. `/` отделяет параметры, которые передаются только по месту. `*` без имени
   делает все последующие параметры именованными.
4. `def f(*args)` собирает аргументы в кортеж, `f(*values)` разбирает
   последовательность на отдельные аргументы. Направление действия символа
   противоположное.
5. Ключи именованных аргументов обязаны быть строками; Python проверяет это
   при сборке вызова, до входа в тело, и поднимает `TypeError`.
6. Уместна в обёртках, посредниках и функциях с действительно переменным
   набором значений. Вредит в публичном API: скрывает контракт и молча
   принимает опечатки.
