## Что исключено и почему

Источники с лицензиями **NC/ND** или без явной лицензии удалены из проекта
целиком (реестр, копии лицензий, клоны, инвентарь фрагментов): их материал не
копировался и не перерабатывался. Это соответствует правилу проекта: открытый
GitHub — не разрешение на использование.

## Как отбирались фрагменты

1. Проверка лицензии на конкретной ревизии (текст, код, изображения, упражнения — отдельно).
2. Оценка качества: глубина, точность, актуальность Python 3.14, рабочие примеры,
   педагогическая последовательность, оригинальность покрытия.
3. Для каждого понятия — один основной источник; остальные дополняют уникальным.
4. Инвентарь `fragments.yaml` фиксирует файл, диапазон строк, понятия, лицензионный
   вердикт и рекомендуемое действие.

## Ограничения

- Без LLM-бэкенда Graphify индексирует документы структурно (AST/структура Markdown);
  семантическая экстракция документов выполняется host-agent-проходом.
- Материал перерабатывается выборочно: не все фрагменты реестра вошли в книгу.
